# 展位布光预览系统

面向会展搭建公司设计组的三维展位布光预览工具。React + PixiJS(Mesh + 自定义 GLSL 着色器),按透视投影渲染展位,光斑、叠色、软阴影全部在片元着色器内按物理模型实时计算。

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 生产构建
node scripts/smoke.mjs   # 运行时冒烟测试(需先启动 dev,自动装 playwright chromium)
node scripts/smoke2.mjs  # 交互流程测试(拖拽/对比/审核流/导出)
```

## 功能对照

- **工作流**: 客户下单建项目(名称/客户/截止时间) → 制作员按镜头制作、提交审核 → 主管审核通过交付或退回(返工次数+1) → 通过后打包交付。项目状态、返工次数、截止倒计时(超期标红)全程可见,数据存 localStorage。
- **展位本体**: 地面、后墙、左墙、展台(台面+立面)、顶架(横梁)、立柱,先搭本体再放灯。
- **灯具**: 射灯 / 洗墙灯 / 灯带,每盏可调 位置X/Z、高度、色温(2700–6500K)、亮度、开合角度、瞄准点、开关;每镜头最多 12 盏。
- **光照计算**(着色器 + JS 同一套模型):
  - 锥角 + 软化边缘 → 地面/立面上的光斑形状;
  - 多灯重叠处 RGB 直接叠色;
  - 墙体/立柱/展台沿作为遮挡线段,面光源 5 次采样 → 软阴影,半影宽度随灯距与遮挡距离自然变化;
  - 白天/夜间两档环境光;
  - 一键关阴影只看光斑。
- **照度统计**: 地面 6×4 个 1m 区域,每区 4×4 采样,输出各区平均照度与均匀度 U0;低于阈值的区域在地面标红并列入暗区清单,阈值可调。
- **交互**: 拖拽空白处旋转/俯仰,滚轮缩放;点击灯选中,拖拽灯手柄在顶架平面换位,拖拽瞄准点改变照射方向。
- **方案对比**: 当前灯位一键存为方案 B,改动方案 A 后对比两套的暗区数量、平均照度、均匀度。
- **导出**: 布光图 PNG(当前镜头渲染结果)、灯位表 CSV(全镜头全方案,Excel 可直接打开)、交付包 JSON(项目数据+统计+图+表)。

## 结构

```
src/model.js      展位几何、遮挡体、灯具模型、照度/阴影/统计计算、项目工作流数据
src/glsl.js       顶点/片元着色器(GLSL ES 3.00)
src/math.js       透视投影矩阵、轨道相机、射线求交
src/BoothView.jsx PixiJS 画布:Mesh 表面、光照 uniforms、手柄与拖拽、暗区标红
src/App.jsx       界面:项目/镜头/状态流、灯光面板、统计、对比、导出
scripts/          Playwright 冒烟与交互测试
```
