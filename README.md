# 醒狮三维骨骼动画编辑器

基于 **SolidJS + WebGL2** 的醒狮团角色骨骼动画编辑器。狮头、前肢、狮被、狮尾按部件拆分,骨架树拖拽建层级,双骨架蒙皮狮被,关键帧 / 曲线编辑 / 序列帧导出 / 动作库 / 批量质检全流程。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 部件拆分导入 | 内置狮头/前肢×2/狮被/狮尾;支持导入 OBJ 作为自定义部件 |
| 骨架树父子层级 | 左侧面板拖拽骨骼到目标骨骼即改父级(防环);「静止姿态」模式摆初始姿态 |
| 部件挂骨骼 + 绑定点偏移 | 检查器中选绑定骨骼,位置/旋转偏移可调 |
| 关节活动范围 | 每骨骼 XYZ 三轴 min/max;「强制限位」开启时拖手柄实时钳制 |
| 旋转手柄摆姿势 | 视口内三色圆环,拖动即在当前帧自动落旋转关键帧 |
| 狮被双骨架形变 | 狮被为蒙皮网格,权重横跨狮头骨架链(颈/头)与狮尾骨架链(尾根~尾节),CPU 蒙皮逐帧驱动 |
| 时间轴关键帧 | 位移/旋转双通道;拖动移动、Shift 多选、复制/粘贴、删除、左右镜像(自动配对左/右骨骼并取反相应轴) |
| 曲线编辑 | SVG 曲线图,拖圆点改帧/值,贝塞尔方形手柄调缓动;贝塞尔/线性/缓入缓出随时切换 |
| 预览与循环区间 | 帧率可调,播放/暂停,时间轴上拖循环区间(边缘缩放、整体平移) |
| 导出序列帧打包 | 按循环区间逐帧渲染 PNG,附 meta.json,打包 ZIP 下载 |
| 动作库 | 条目记录帧数/帧率/时长,状态流转:草稿→质检中→已放行/已退回;localStorage 持久化 |
| 质检 | 批量自动检查:缺关键帧、关节超限(逐帧采样)、狮被穿插(蒙皮顶点 vs 头/躯干/尾碰撞体);按 严重/一般/提示 分级;复核员逐条确认或驳回;存在待复核或已确认的严重问题时禁止放行,只能退回重做 |

## 操作速查

- 视口:左键拖环旋转骨骼 · 点击关节球选骨骼 · 空白拖动转视角 · 右键平移 · 滚轮缩放
- 时间轴:单击选关键帧(Shift 多选)· 拖动移动 · 双击跳到曲线编辑
- 检查器:`K 旋转/位移/全部` 手动打关键帧
- 菱形颜色:黄=贝塞尔 蓝=线性 绿=缓入缓出

## 测试

```bash
node smoke/unit.mjs    # 核心模块单元测试(插值/FK/镜像/ZIP/OBJ)
node smoke/smoke.mjs   # 端到端:编辑器→动作库→质检→放行
node smoke/smoke2.mjs  # 端到端:空动画质检拦截→退回 + 序列帧导出 ZIP
node smoke/smoke3.mjs  # 端到端:手柄拖动落关键帧 + 左右镜像
```

端到端测试用 puppeteer-core 驱动本机 Chrome(SwiftShader 软渲染 WebGL)。
