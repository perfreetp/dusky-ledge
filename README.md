# 车间地面安全标线与区域划分矢量编辑器

面向工厂 EHS 与车间主任的标线绘制工具：在厂房底图上拉通道线、禁停区、人行道、工位框，
支持路径布尔运算、吸附、多选对齐、规范斜纹填充、版本归档、SVG 交付与老带新考核。

**技术栈**：Vue 3 + TypeScript · WebGPU 渲染（自动回退 Canvas2D）· Node.js + SQLite · Vite

---

## 快速开始

```bash
npm install
npm run dev          # 同时启动 API (127.0.0.1:8787) 与前端 (localhost:5173)
```

首次启动时若数据库为空，会自动写入一份示例车间（1 个车间 + 1 个标线方案 + 1 个已发布的考核任务），
可以直接打开体验。也可以手动执行 `npm run seed`。

浏览器打开 <http://localhost:5173>。

生产构建：

```bash
npm run build        # 类型检查 + 打包到 dist/
npm start            # API 同时托管 dist/，单端口 8787 提供服务
```

测试：

```bash
npm test             # 67 个单元测试：几何、布尔、吸附、评分、SVG、历史栈
npm run e2e          # 24 项浏览器端验收（需先启动 dev 服务）
```

> **WebGPU**：需要 Chrome / Edge 113+。没有 WebGPU 时自动切换到 Canvas2D 渲染，
> 功能不缺失但大图纸会变慢；界面左下角会标注当前渲染后端。

## 功能与实现要点

### 1. 路径布尔运算（难点一）

- 基于 **Clipper**（0.01 mm 整数精度）实现并集 / 交集 / 差集 / 异或。
- **线自动展开为线宽带**：中心线按线宽偏移成闭合轮廓后再参与布尔，所以两条通道线可以真正"并"成一个十字路口。
- **结果必定闭合**：布尔结果由 `PolyTree → ExPolygons` 读取外轮廓与孔洞，逐环清洗（去重顶点、去共线点），
  区域按 even-odd 规则填充，孔洞不会漏。
- **差集**以第一个选中对象为主体，其余作为裁剪，可挖出孔洞（多环结果）。

相关代码：`src/core/clipper.ts`、`src/core/ops.ts`（`combineFeatures`）、`src/core/math.ts`（`groupRings`）。

### 2. 两条相交线合并成一条流水线（难点二）

- `mergeOpenPaths` 把所有选中线段构造成**平面图**：端点按容差合并为同一节点，线段在他线交点处打断。
- 随后从自由端点出发沿图行走，在每个交叉点选择**最接近直行**的后续边（点积最大），
  T 型交叉处主线保持完整、支线单独成段，不会在拐角处"折返"。
- 合并后生成一条 `流水线` 要素，保留原线宽与样式，并在 `meta.mergedFrom` 记录来源。

相关代码：`src/core/clipper.ts`（`mergeOpenPaths`）、`src/core/ops.ts`（`mergePathFeatures`）。

### 3. 吸附（端点 / 中点 / 线段 / 网格）

- `SnapIndex` 用均匀网格分桶所有顶点、中点、线段，查询为 O(1) 邻域搜索。
- 优先级按**距离 ÷ 权重**比较：端点 3、中点 2、中心 1.6、线段 1、网格 0.7，
  因此 40 mm 外的中点会胜过 35 mm 外的线上点，但 5 mm 的线上点仍优先。
- 吸附命中时画布显示粉色标记与类型（端点/中点/线上/网格），便于确认。

相关代码：`src/core/snap.ts`。

### 4. 多选对齐与等距分布

- 六个方向对齐（左/水平居中/右/顶/垂直居中/底），以选区包围盒为基准。
- 等距分布按**包围盒之间的空隙均分**，两端对象不动，中间对象自动排布；
  另有按中心点均分的模式。
- 附带旋转（围绕选区中心）、水平/垂直镜像、缩放。

相关代码：`src/core/align.ts`。

### 5. 撤销 / 重做 ≥ 50 步

- 文档不可变，历史栈保存**整份文档快照**；默认上限 200 步（下限强制 50 步），
  测试验证 60 次独立编辑可逐个撤销并完整重做。
- 拖拽、连续改数值通过 `coalesceKey` 合并为一步，避免撤销栈被细碎操作淹没。

相关代码：`src/core/history.ts`、`src/state/editor.ts`。

### 6. 规范线型与斜纹填充（难点三：几万条斜纹实时预览）

- 七类规范图元：主通道 / 人行 / 消防（线），禁停 / 工位 / 物料 / 危险（面），
  各自带默认线宽、颜色、线型与填充，一键套用。
- 斜纹支持单向斜纹、交叉斜纹、网格、点阵；可调间距、角度、纹宽、双色交替（黄黑警示）。
- 斜纹生成是**精确几何**而非位图：每条纹线在旋转坐标系里求与轮廓边的交点，按奇偶配对裁切，
  因此孔洞内不会有纹线，导出 SVG 也是真实线段。
- WebGPU 侧每条纹线是**一个实例**，顶点着色器把线段扩成四边形，整份图纸的斜纹是
  **单次实例化 draw call**；缩放到纹距不足 2.5px 时自动隔条绘制（LOD），避免摩尔纹与填充率浪费。

实测：300 个斜纹区域共 **25,451 条纹线**，几何构建 35 ms，稳定 **60 fps**。

相关代码：`src/core/hatch.ts`、`src/render/scene.ts`。

### 7. 按车间存版本

- 车间（Workshop）→ 方案（Plan）→ 版本（Version）三级结构，SQLite 持久化。
- 「保存并发布版本」生成不可变快照（含发布人、说明、时间）。
- 版本库可勾选两个版本**对比差异**（新增/删除/修改的对象及字段），也可恢复旧版本到编辑器。

相关代码：`server/db.ts`、`src/views/VersionsView.ts`。

### 8. 导出 SVG 给施工方

- 1 个绘图单位 = **1 mm**，`width="36000mm"`，可直接 1:1 打印/放线。
- 每个对象一个命名图层（含 `inkscape:label`，Inkscape 中显示为图层）。
- 斜纹以 `<clipPath>` + 真实线段输出，**不依赖浏览器 pattern 支持**；裁剪按半个边框宽内缩，纹线不会溢出轮廓。
- 描边以填充几何输出（精确线宽，不依赖渲染器的 stroke 实现）。
- 附带比例尺、对象名称与尺寸标注。另有 GeoJSON、工程量 CSV、PNG 预览导出。

相关代码：`src/core/svg.ts`。

### 9. 老带新培训考核（难点四）

1. **老师出题**：选一块厂房底图（内置示例或已有方案），设定各类型线宽、数量、位置容差与评分权重；
   参考答案保存在**服务端**，学员端接口不会下发。
2. **学员练习**：填写姓名后在空白底图上照规范绘制，支持本机暂存。
3. **自动评分**：把所有对象"材质化"为实际涂装区域（线 → 线宽带，面 → 环），按类型计算：
   - **覆盖度**：与参考答案的 IoU（并集 / 交集）；
   - **线宽**：对数偏差与容差比较，超差线性扣分；
   - **闭合度**：区域是否有有效闭合轮廓、有无零长度边。
   缺失、多余、位置偏差、未闭合都会生成**具体错题条目**（含期望值与实际值）。
4. **老师复核**：可逐条调整扣分并写评语，最终成绩 = 100 − 扣分合计，与明细完全一致。
5. **成绩汇总**：平均分、最高/最低、及格率、分数分布、高频错题 Top 10，可导出 CSV。

相关代码：`src/core/grading.ts`、`src/views/PracticeView.ts`、`src/views/GradeView.ts`、`src/views/SummaryView.ts`。

## 单位与坐标

- 内部一律使用**毫米**；图纸默认 24000 × 16000 mm。
- 底图上传后可「校准」：在图上点两个已知距离的点，输入实际米数，系统按比例缩放底图，
  之后绘制的标线即为真实尺寸。

## 目录结构

```
shared/            前后端共享类型、示例车间数据
src/core/          几何内核：math / clipper / hatch / stroke / snap / align / ops / history / grading / svg
src/render/        WebGPU 场景渲染器、Canvas2D 覆盖层（网格、手柄、吸附、标定）
src/state/         编辑器状态（文档、相机、选区、草稿、历史）
src/components/    画布组件与交互（指针、键盘、绘制状态机）
src/views/         方案、编辑器、版本、培训、成绩、汇总、帮助
server/            Express + SQLite API
tests/             Vitest 单元测试
scripts/e2e.mjs    Playwright 浏览器验收
```

## API 速览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET/POST | `/api/workshops` | 车间列表 / 新建 |
| GET/POST | `/api/plans` | 方案列表 / 保存（可同时发布版本） |
| GET/POST | `/api/plans/:id/versions` | 版本列表 / 发布版本 |

| POST | `/api/submissions` | 学员提交并自动评分 |
| POST | `/api/submissions/:id/review` | 老师复核打分 |
| GET | `/api/tasks/:id/summary` | 成绩汇总与高频错题 |
