# 体素地层实验室 · 考古实习教学工具

面向考古实习教学的三维体素地层建模与考核工具。学员在探方网格中按地层号逐层放置体素，
系统按层数、体积占比、镜像一致性自动评分；教师出题、设截止时间、逐份复核；错题汇总到教学看板。

原生 TypeScript + Web Components + WebGL2，无前端框架、无运行时依赖，构建产物是单个 JS 文件。

## 运行

```bash
npm install
npm run dev        # 构建 + 在 http://localhost:5173 启动静态服务
# 或
npm run build      # 只构建 dist/app.js
npm start          # 只起服务
```

打开 `index.html` 也可以通过 `file://` 直接运行（`dist/app.js` 是 IIFE，无模块加载问题），
但建议走本地服务，避免个别浏览器对 `file://` 的存储限制。

- `npm run typecheck` — 严格模式类型检查
- `npm test` — 核心算法单元测试（Node 内置 test runner，56 项）
- `node tools/e2e.mjs` — 无头 Chrome 端到端流程（需要本机安装 Chrome，见下）

端到端脚本使用 `playwright-core` 驱动本机已安装的 Chrome，
路径在 `tools/harness.mjs` 的 `CHROME` 常量里，如路径不同请自行修改。

## 界面

三个模式，顶部切换：

| 模式 | 用途 |
| --- | --- |
| 学员建模 | 探方里逐层放置体素、框选、镜像编辑、减面、导出、提交 |
| 教师出题 | 按探方尺寸与地层数出题、设截止时间、复核学员提交 |
| 教学看板 | 提交量、自动/复核分数、错题分布、层位缺失热点、失分项排行 |

数据保存在浏览器 `localStorage`（键 `strata-voxel-lab/v2`，工作区草稿在
`strata-voxel-lab/workspace/v2`）。清空站点数据即重置全部题目与提交。

## 学员端操作

工具（键盘）：放置 `B` / 擦除 `E` / 隐藏 `H` / 框选 `R` / 吸色 `I` / 浏览 `V`。

- **放置**：单击落一块；按住拖拽沿表面连续放置。落位会被约束在当前层高度范围内，
  不会溢出到相邻地层。拖拽时按“列”填充该层，避免射线反复命中刚放下的那一格。
- **镜像是开关**（`M`）：开启后每次落块、擦除、隐藏同时作用于左右对称的两格；
  奇数宽度的探方中轴只作用一格。
- **地层面板**：单击设为当前层，双击只显示该层；眼睛图标切换单层显示/隐藏。
  切换当前层时相机会自动把视线带到该层，方便处理深处的堆积。
- **框选**（`R`）：拖出矩形选区（按住 `Shift` 可跨层）。选中后工具条出现
  「复制 / 平移到本层 / 复制到本层 / 填充 / 清除」，也可在图层间整体平移。
  `Ctrl+C` 复制、`Ctrl+V` 复制到本层、`Delete` 清除选区、`Esc` 取消选区。
- **隐藏与恢复**：隐藏的体素不参与射线拾取，因此点不到；工具条上的
  「显示隐藏体素」会把它们以半透明显形，此时可以点回去恢复。
- **整片替换土色**：把探方内（或框选范围内）某种土色一次性替换为另一种。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Shift+Z`，最多 60 步；一整笔拖拽合并为一步。

视角：右键/中键/`Alt`+左键拖拽旋转，`Shift`+拖拽平移，滚轮缩放，双击复位。

### 面数与减面

右侧「面数与导出」实时显示三角面数、面数预算与余量。

渲染前会做两件事：

1. **单面剔除**：相邻体素之间的共享面不生成，只保留朝向外部、朝向相机的一侧；
   OpenGL 侧同时开启背面剔除（`CULL_FACE` / `BACK`）。
2. **同材质合并**：共面、同朝向、同材质的四边形贪心合并成尽可能大的矩形，
   每种土色最终只上传为一张合并网格，一次 `drawElements`。

超过预算时meter 变红并提示减面。**减面**把若干个体素块按多数材质合并成更粗的体素
（网格整体按比例缩小、导出时再按同一倍数放大，外形尺寸不变），
面数大致按合并边长的平方下降。减面只影响导出的模型，不修改当前体素网格。

导出：`OBJ` + `MTL`（每种土色一个材质），带法线，三角剖分。

### 提交

提交前弹出自动核对预览：层数、各层体积占比（含目标值竖线）、镜像一致率、面数、问题清单。
提交后系统计分，教师再复核。

## 评分规则

自动分满分 **70**：

| 项 | 权重 | 判定 |
| --- | --- | --- |
| 地层数 | 30 | 已建层数达到要求层数，且自上而下连续不缺层 |
| 体积占比 | 25 | 各层体素占比与「层厚 / 总厚度」的理论占比比较，单层容差 8% |
| 镜像一致性 | 15 | 左右对称格材质相同的比例，≥ 95% 视为通过 |

- 题目不要求镜像时，镜像的 15 分按 30:25 并入前两项（变为 39 / 31），总和仍为 70。
- 层序不连续（中间缺层）在层数项上额外乘 0.7。
- 三角面超预算、存在隐藏体素只作为「问题」提示教师，不直接扣自动分。

教师复核满分 **30**，可逐份给分并写评语。总分 = 自动分 + 复核分（满分 100）。

自动核对产生的错题（缺层、占比偏差、镜像不对称、面数超预算、隐藏体素）
会以标签形式进入教学看板的错题分布、层位缺失热点与失分项排行。

### 实现要点

- **拾取**按体素逐格推进：射线先与整个探方 AABB 求交得到进入格，之后每步用
  Amanatides–Woo DDA 跳到下一个格，命中第一个满足条件的体素，返回命中格与命中面法线。
  放置位置取命中格沿法线向外一格。
- **增量网格化**：探方按 8³ 分块，每块带有 1 格邻接 padding 参与剔除判断，
  只输出落在块内的面，因此块之间既不重复也不漏面（单元测试用表面积求和校验）。
  `VoxelGrid` 维护变更日志，编辑器把变更点映射到受影响的分块，拖拽时每笔只重算少数块。
- **评分是纯函数**，输入是各层体素计数、占比、镜像一致率、面数，便于单测与回放。

## 已知边界

- 镜像以 `nx-1-x` 为对称轴；`nx` 为奇数时中轴列只影响自身。
- 框选平移时若块高大于目标层厚，超出目标层的行会被跳过并在提示里给出数量。
- 减面是整块多数材质取样，层界在粗网格下会变模糊；这是与面数预算的取舍。
- 数据只存在本机浏览器，没有账号与服务端；用于课堂练习而非正式成绩归档。
