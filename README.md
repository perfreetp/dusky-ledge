# 剖面工坊 · 智慧工厂教具体素建模

给培训中心做设备剖面教具的体素建模工具。半米一格搭建，按外壳 / 机架 / 传动 / 电控四组分别上色与显隐，
沿 X/Y/Z 剖切看内部结构，镜像补齐、框选复制粘贴、单格材质与透明度，最后剔除内部面合并成外观面并导出 glb。

Vue 3 + WebGPU（原生 WGSL 渲染管线，不依赖 three.js / babylon）。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 生产构建到 dist/
```

浏览器需支持 WebGPU（Chrome / Edge 113+）。虚拟机会退回到 SwiftShader，能出图但帧率低。

## 验证

npm run dev                 # 另开一个终端

2 万面拦截，以及需求单 → 派工 → 提交 → 质检打回 → 看板的全流程。

## 建模台

**坐标系与尺度**：单格 0.5 m。网格坐标 x 向右、y 向上、z 向前；世界坐标以工作台中心为原点，
所以格 (x,y,z) 的世界位置是 `((x - sx/2) * 0.5, y * 0.5, (z - sz/2) * 0.5)`。

| 区域 | 功能 |
| --- | --- |
| 左栏 | 设备预设、工具、四组显隐与单独查看 |
| 画布 | 左键拖动旋转，右键/中键/Shift 平移，滚轮缩放，右下方位按钮切正视图 |
| 右栏 | 材质与透明度、三轴剖切、剪贴板、我的工序、导出核算 |

**工具快捷键**：`Q` 观察、`B` 落格、`E` 擦除、`R` 改属性、`I` 取样、`M` 框选、`P` 粘贴定位。
`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做，`Ctrl+C/X/V` 复制剪切粘贴，`Del` 删除选区，`Esc` 取消选区。

- **落格**：在命中面的外侧落一格；指针顶到工作台边界时覆盖命中格本身，不会点了没反应。
  笔刷半径 1–4 格，按住拖动连续填。
- **擦除**：删掉命中的格子，支持笔刷半径。
- **改属性**：按当前材质与透明度套用到点中的格。选中一片后可在材质面板「套用到选区整片」。
- **框选 + 复制粘贴**：拖矩形框出三维区域，`Ctrl+C` 进入「粘贴定位」，画面上移动指针会显示
  **落点包围盒**；压到已有体素时框变红并提示覆盖格数，越界时自动吸附回范围内。开镜像会同时画出
  对侧的紫色落点框，粘贴时两边一起补。
- **镜像对称**：`X`/`Y`/`Z` 三个轴可选，沿轴中心面镜像；落格、擦除、改属性、粘贴都会自动补齐另一侧。
- **切片剖切**：X/Y/Z 三轴独立滑杆，`≥`/`≤` 切换切哪一侧。被切掉的部分不参与渲染也不参与拾取，
  剖切面会做暗色封边。
- **材质与透明度**：8 种材质（不锈钢、铸铁、铝、玻璃、亚克力、橡胶、铜、安全黄）+「随组色」。
  透明度 7%–100% 量化到 15 档，半透明面单独按相机距离排序后混合。

## 导出

「导出 glb」先弹出核对面板：

- 体素数、逐格外表面（未合并）、合并后三角面
- 四组面数占比，点组名可取消/恢复导出该组并实时重算
- 合并说明：剔除相邻内部面后剩多少四边形面，贪心合并后剩多少，减少百分比
- 超过 **20,000** 三角面时禁用导出按钮并给出减面建议；15,000 以上给橙色提醒

合并算法（`src/voxel/mesh.js`）：对每个轴向定向扫一遍，跳过已有相邻体素的面（内部面剔除），
同色同朝向的共面格用贪心矩形合并成一个大四边形。四组在**一次遍历**里完成，组与组之间的相邻面
同样剔除，所以导出面数与核对面板数字严格一致（验证脚本里有对应断言）。

GLB 是自己按 glTF 2.0 二进制规范拼的（`src/export/glb.js`），四组各一个 mesh + 一个材质，
POSITION/NORMAL 用 float32、索引用 uint32，每个 bufferView 4 字节对齐。

## 工序流转

三个页面在顶栏切换：

1. **需求单**：培训中心提「设备型号 + 必须露出的部件 + 数量 + 交期 + 补充说明」。筛选、搜索、详情。
2. **派工与质检**：组长把待派工或返工单派给师傅（派工对话框列出师傅在制量）；
   师傅在右栏「我的工序」载入关联预设、建模、勾选自检项后提交质检；
   质检逐条核对「要露出的部件」，通过或打回；打回必须写意见，并累加返工次数。
3. **看板**：按人统计承接/完成/在制/待质检/返工次数/一次性通过率，按单列出全部需求单与动态。

数据存在 localStorage（`profile-workshop:workflow:v1`），顶栏右上角可切换当前身份（组长 / 师傅 / 质检）
体验不同角色看到的界面。需求单页可「恢复示例数据」。

## 渲染管线

阴影贴图（2048 正交）→ 前向着色写入颜色 + 世界法线（MRT，rgba16float）→ SSAO（12 采样半球）→
后期合成（ACES + sRGB + 暗角）→ 叠加线框。半透明体素在不透明物体之后、按相机距离从远到近排序绘制。
叠加线框用实例化四边形做屏幕空间挤出，按深度图判断遮挡，网格线允许透视显示、实体辅助线被挡住就丢弃。
