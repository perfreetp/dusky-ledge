# 绸吊飞人 · 三维角色骨骼动画编辑器

面向杂技团绸吊 / 空中飞人动作教学的纯前端三维骨骼动画编辑器。
**原生 TypeScript + Web Components + 自研 WebGL2 渲染器**，无 three.js / 无前端框架。

## 技术栈

| 层 | 实现 |
| --- | --- |
| 语言 | TypeScript 5（strict） |
| UI | 原生 Web Components（Custom Elements + Shadow DOM） |
| 渲染 | 自研 WebGL2（蒙皮着色器、Gizmo、射线拾取、权重可视化） |
| 数学 | 自研 vec3 / quaternion / mat4 / 贝塞尔缓动库 |
| 持久化 | IndexedDB（项目、订单、动作版本） |
| 导出 | JSZip 打包 PNG 序列帧 + keyframes.json + manifest.json |
| 构建 | Vite 5 |

## 快速开始

```bash
npm install
npm run dev      # 开发，自动打开 http://localhost:5173
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

内置四个演示身份，右上角随时切换：

- **李教练**：填写动作要点、难度等级建单并分派
- **王动画 / 赵动画**：接单后进编辑器制作、导出、选版本送审
- **张团长**：抽查，通过归档或填写原因打回（自动累计返工次数）

## 业务工作流

```
教练建单(要点+难度) → 分派动画师(自动建项目) → 动画师制作
   → 选版本送审 → 团长抽查 ┬─ 通过归档
                          └─ 打回(返工+1，原因回传)
```

**看板**只呈现每人的完成量、返工次数与在制单数，不掺杂订单细节。

## 编辑器三大模式

### 1. 骨架模式
- 内置 19 根标准人形骨架（骨盆→脊柱→头颈、四肢、手脚），脚底对齐 y=0
- 增删骨骼（删除时子骨骼自动上挂，层级不断裂）
- 树形面板设置父子关系（带成环检测）、绑定姿态的局部位移/欧拉角旋转、骨段长度
- 视口中彩色关节八面体 + 骨段圆柱，Gizmo 支持位移 / 旋转两种操纵
- 一键生成低模人形网格（自动刷权重），或导入 OBJ 网格

### 2. 权重模式
- 选骨骼作为笔刷，在视口点击/拖过顶点刷权重（替换或叠加，每顶点 4 槽）
- **网格按骨骼颜色显示影响范围**（权重加权混合骨骼色）
- **权重未刷满（和 ≠ 1）的顶点实时标红**，面板显示未刷满顶点计数
- 全部归一化、按最近骨段自动刷权重

### 3. 动画模式
- 时间轴多轨道显示各骨骼关键帧，**关键帧可拖拽改时间（自动吸附帧）**
- 选中关键帧后调节 **贝塞尔切线手柄（缓入 inX / 缓出 outX）或勾选匀速线性段**
- 一键打帧（位移+旋转）、删帧；**复制某一帧完整姿势粘贴到另一段时间**
- 播放时按缓动函数对位置 lerp、旋转 slerp，**实时插值驱动蒙皮骨架**
- **脚底穿地检测**：低于地面的顶点红色高亮，面板统计穿地顶点数与最低点 Y
- 骨骼 / 网格可独立切换显示，地面高度可调

## 版本与导出

- 同一项目可保存多个动作版本（深拷贝隔离），送审时选择其中一个
- 导出当前镜头逐帧渲染：`frame_00000.png …` 序列帧 + `keyframes.json`（骨骼层级、每帧时间/位姿/切线）+ `manifest.json`
- **重新导出沿用上一次的 startFrame，帧号严格对齐**，便于替换更新

## 目录结构

```
src/
├─ core/        # 类型、数学库、IndexedDB、状态中心、骨架/网格/动画领域逻辑
├─ renderer/    # WebGL2 渲染器与 GLSL 着色器
├─ editor/      # 视口交互、时间轴、序列帧导出、编辑器工作区
├─ ui/          # Web Components：外壳、顶栏、看板、订单
└─ main.ts      # 入口（先初始化持久化再注册组件）
scripts/
└─ smoke-test.mjs   # CDP 端到端冒烟测试（23 项断言）
```

## 端到端测试

需先 `npm run dev`，再启动带远程调试的 Chrome：

```bash
chrome --headless=new --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-test about:blank
node scripts/smoke-test.mjs
```

覆盖：登录建单分派 → 编辑器网格生成 → 骨骼增删 → 权重统计 → 关键帧/切线/复制姿势 →
播放插值 → 穿地检测 → 多版本 → 两次导出帧号对齐 → 送审打回 → 看板返工统计 → IndexedDB 持久化。
