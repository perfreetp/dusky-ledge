# 攀岩馆线路支点布置与批次放行三维编辑器

Svelte 4 + Babylon.js 7 + Vite。

## 运行

```bash
npm install
npm run dev    # http://127.0.0.1:5173
npm run build  # 产物在 dist/
```

## 四个界面

1. **线路编辑** — 导入岩板排布(JSON)或加载示例;从支点库拖支点入场景;左键按包围盒点选,选中出三轴平移/旋转手柄;松手沿板面法线自动吸附贴紧;跨板缝与支点最小间距(8cm)实时碰撞检测,超限标红并显示实际距离;同板按线路着色,一线一色。
2. **出图与统计** — 一键正视图/俯视图各出一张 1920×1200 PNG;按线路统计支点数、螺栓数、岩板占用比例。
3. **提交检查** — 整批提交后自动检查,按三级列出:一级支点干涉、二级锚栓压板缝、三级超高支点(>4m)。
4. **复核放行** — 复核员逐条确认或驳回(驳回必填原因);全部确认达标才可整批放行,有驳回即整批退回并记录原因。编辑变更会使批次回到草稿态,需重新提交。

数据自动保存在浏览器 localStorage。

## 岩板排布 JSON 格式

```json
{
  "panels": [
    { "id": "P1", "name": "板-11", "x": 0, "y": 1.22, "z": 0,
      "width": 1.22, "height": 2.44, "angleY": 0, "thickness": 0.018 }
  ]
}
```

坐标系:X 水平、Y 竖直、Z 朝岩壁外侧;`angleY` 为绕竖轴倾角(度)。

## 检查阈值(src/store.js 顶部可调)

| 常量 | 默认 | 含义 |
|---|---|---|
| `MIN_GAP` | 0.08m | 支点间最小净距 |
| `BOLT_SEAM_MARGIN` | 0.03m | 锚栓距板缝最小距离 |
| `HEIGHT_LIMIT` | 4.0m | 支点限高 |
