# MC3D · 机械制图三维布尔建模与三视图工具

面向机械制图课程的纯前端教学工具：SolidJS + WebGL2（three.js）实现三维实体布尔建模、
剖切出剖面线、正交三视图自动生成与 SVG 线稿导出，并内置作业布置、自动核对、
老师复核打分与班级看板的完整教学闭环。

## 功能清单

### 三维建模
- **体块库拖入**：长方体、圆柱、棱台（四棱台/可调棱数圆台），HTML5 拖放落到地面平面
- **布尔运算**：并集 / 差集 / 交集，基于 `three-bvh-csg`（BVH 加速），特征树可随时切换运算
- **布尔后选面改尺寸**：三角面携带 `aFeature`/`aFace` 自定义属性贯穿 CSG，
  点击实体表面可定位到来源特征与语义面，支持沿面法线拖拽或在面板输入尺寸
- **捕捉对齐**：移动体块时自动吸附到已有体块的顶点（橙）、边中点（蓝）、面心（绿），22px 屏幕阈值
- **撤销/重做**：结构化快照历史栈（上限 100），拖拽手势整段合并为一条历史，支持 Ctrl+Z / Ctrl+Shift+Z

### 剖切
- 任意方向剖切平面（预设 −Y/−Z/+X，也可自定义点与法线）
- 剖切盒与实体求交，剖切面三角面打 `aCap` 标记并贴 45° 剖面线纹理
- 三视图中剖切面输出独立填充与按间距裁剪的剖面线（SVG clipPath）

### 三视图与 SVG
- 正交相机自动生成主视 / 俯视 / 左视，第一角画法布局（主视左上、左视右、俯视下）
- 浮点深度纹理判定可见线 / 隐藏线（隐藏线虚线）
- 线稿提取：顶点容差焊接 → 语义面 + 几何法线双重过滤剔除三角剖分边与 T 型接缝
  → 2D 共线聚类合并 → 深度判定，圆柱曲面只输出轮廓线不输出碎面
- 一键导出标准 SVG（含图框、标题、可见/隐藏线、剖面线）

### 教学闭环
- 老师布置带尺寸要求的作业（目标体积与容差、要求的布尔运算、最少体块数、是否要求三视图）
- 学员提交后自动核对：体积偏差、三视图数量、运算类型、体块数量、剖切状态
- 老师复核打分（百分制）与评语，可载入学员模型查看
- 班级看板按作业聚合提交通过率、平均分、错题项与常见错法人次
- 作业/提交/身份均存 localStorage，刷新不丢失

## 技术栈

| 层 | 选型 |
|---|---|
| UI 框架 | SolidJS 1.9（store + 细粒度信号） |
| 3D / WebGL2 | three.js 0.187，OrbitControls，自定义 onBeforeCompile 材质 |
| 布尔内核 | three-bvh-csg 0.0.18 + three-mesh-bvh |
| 构建 | Vite 8 + vite-plugin-solid，TypeScript 严格模式 |
| 测试 | Playwright（playwright-core 驱动系统 Chrome，SwiftShader 软渲染） |

## 关键设计说明

- **面属性贯穿布尔**：`Evaluator.attributes` 声明 `aFeature/aFace/aCap/aSel`，
  CSG 切割插值后仍可从三角面反查来源特征，是"布尔后选面改尺寸"的基础。
- **求值缓存**：模型版本号变化才重新布尔，仅面选择变化时重写 `aSel` 高亮属性，
  建模视口、三视图、体积核对共享同一结果。
- **线稿去碎边**：CSG 输出网格不共享索引且带 T 型接缝，无法直接用 EdgesGeometry。
  本工具先做 0.05mm 顶点焊接，再用"语义 aFace + 15° 法线夹角"双重判定剔除同面内部边，
  单面接缝边通过端点邻接面共面判定剔除，最后在 2D 投影域共线聚类合并为完整直线。
- **深度可见性**：1024px 浮点深度缓冲离屏渲染，边中点采样与 3 像素容差比较，
  被实体自身遮挡的边输出为虚线隐藏线。

## 已知边界

- 数据存浏览器 localStorage，清缓存会丢失教学数据（多机部署需替换为后端 API）。
- 线稿提取按 48 分段圆柱调优，极端低分段（<8）曲面轮廓可能出现折线。
- 剖切为单平面；多平面阶梯剖/旋转剖未实现。
