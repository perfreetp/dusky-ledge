# 太湖石体素建模与档案加工工具

面向园林假山施工队的太湖石加工工具:扫描点云粗格化为体素 → 逐层编辑 → 网格合并减面 → 导出 GLB / 体素清单,并对每块石头的加工过程建档、存版本、比对、出加工记录单。

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产物在 dist/
```

技术栈:Vue 3 + Vite + Three.js(WebGL2 渲染),档案数据存浏览器 IndexedDB,无后端。

## 功能对照

| 需求 | 位置 |
| --- | --- |
| 点云粗格化 | 左栏「点云导入」,支持 ASCII PLY / xyz / csv,按当前体素尺寸落格 |
| 逐层编辑 | 中下层面图(俯视 XZ),滑杆/按钮切层,画笔/橡皮 |
| X/Z 同时镜像 | 左栏「镜像对称」两个开关,可单独或同时开,层图上红/蓝虚线为对称轴 |
| 层高/体素 5/10/20cm | 左栏「模型 → 体素尺寸」,切换时自动重采样保形 |
| 选区复制粘贴 | 工具「框选」拖出矩形 → 复制/剪切 → 「粘贴」后点击放置(随镜像联动) |
| 整层平移旋转 | 左栏「整层操作」:X/Z 四向平移、90° 顺/逆时针旋转、清空本层 |
| 石材分色 | 左栏「石材」8 种(太湖石/黄石/英石/灵璧石/千层石/斧劈石/笋石/钟乳石) |
| 光照 | 环境光 + 主平行光 + 补光,标准粗糙度材质 |
| 同色合并 + 减面 | 贪心网格化合并相邻同色面,顶点聚类减面,比例 0–90% 可调 |
| 面数实时显示 | 顶栏与 3D 视图左上角 HUD:体素数/体积/合并面数/减面面数 |
| 导出 | 「导出」:GLB(带顶点色,按当前减面比例)、体素坐标 CSV |
| 建档 | 右栏「建档」:编号、产地、长×宽×高、备注;可按尺寸一键建模型 |
| 版本 | 右栏「版本」:每次加工保存一版(含体素数据与体积/面数统计),状态:草稿/加工中/已审定/已归档 |
| 版本比对 | 右栏「比对」:任选两版,体素数/体积/面数差异 |
| 加工记录单 | 版本条目「加工记录单」→ 弹窗预览,可直接打印 |
| 检索 | 右栏「检索」:按产地模糊、尺寸区间、版本状态组合筛选 |

## 目录结构

```
src/core/voxel.js       体素模型(镜像写入、层平移/旋转、选区、重采样、点云落格)
src/core/mesher.js      贪心网格化(同色合并)+ 顶点聚类减面
src/core/glb.js         GLB(glTF 2.0 二进制)写出
src/core/pointcloud.js  PLY / xyz / csv 点云解析
src/core/db.js          IndexedDB 档案库(stones + versions)
src/components/         Viewport3D / LayerEditor / ToolPanel / ArchivePanel / RecordSheet
```
