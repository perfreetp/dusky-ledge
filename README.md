# 方块工坊 · 体素造型设计与拼搭考级工作台

面向拼装积木品牌的 3D 体素建模与考级 Web 应用。Vue 3 + Canvas 2D + OffscreenCanvas 实现，无 WebGL 依赖。

## 运行

```bash
npm install
npm run dev        # 开发：http://127.0.0.1:5179
npm run build      # 生产构建到 dist/
npm test           # 核心逻辑 + 组件挂载冒烟测试
```

## 功能清单

### 建模工作台
- **等轴测 3D 渲染**：Canvas 2D 逐体素绘制顶面 + 两个可见侧面，三朝向不同光照系数做深浅着色；画家算法按旋转后深度排序，遮挡关系正确
- **视角旋转**：按住拖动整体绕竖直轴（yaw）旋转，滚轮缩放
- **逐面拾取**：离屏 `OffscreenCanvas`（不支持时自动降级普通 canvas）把每个可见面编码成唯一 RGB，`getImageData` 精确命中前后不同层的体素与命中面的法线
- **笔刷编辑**：加体（点在面的法向邻格）、删体，按住可连续拖绘；落点有白色幽灵块预览
- **镜像对称**：X 轴 / Y 轴 / 双轴镜像，加体、删体、粘贴自动扇出对称位；地面与切片上画镜像轴
- **分层切片**：切到指定 z 层单独编辑，其他层半透明且不可拾取；另有独立俯视平面视图，数学反算拾取
- **选择系统**：点选（Shift 多选）、矩形框选（主视图按屏幕中心投影筛选 / 切片视图按网格反算）
- **复制粘贴**：框选一块复制为相对坐标剪贴板，弹窗调 dx/dy/dz 平移，实时预览可粘贴/越界/冲突数量，镜像位同步粘贴
- **同色合并减面**：
  - 贪心网格合并（greedy meshing）把同色相邻暴露面合并成大四边形，给出原始面数 → 合并面数
  - 贪心长方体合并，把一片同色体素归并为大长方体（体素数守恒）
- **导出**：OBJ + MTL（同色面归入同一材质组、四边形保持一致绕序）；逐层拼搭清单 TXT（每层砖块数、颜色明细、全模型用色汇总），页面内也可查看清单弹窗
- 撤销/重做（40 步）、快捷键（1-5 切工具、Ctrl+Z/Y、Ctrl+C/V、Delete）

### 考级流程（老师 / 学员双身份）
- **老师**：任务中心下发任务，设定体素上限与对称要求（不要求/X/Y/双轴，任务内镜像设置对学员锁定）
- **学员**：领取任务拼搭，达到体素上限后无法再加体；提交时系统自动计算：
  - 体素总数、超限判定
  - 对称度（逐体素比对镜像位颜色，按要求轴分别打分）
  - 悬空体素检测、用色数量
  - 综合机器初评分与扣分明细
- **复核台**：老师在只读立体视图中拖动旋转复核，查看初评指标，输入最终成绩与评语改分
- **成绩与错法汇总一页**：平均分、初评/最终分差、五类常见错法（超限、对称不达标、悬空、用色过杂、作品过小）的出现频次与占比条形图、教师评语摘录
- 全部数据（任务、提交、草稿）经 localStorage 持久化，内置一座严格对称且无悬空的演示小房子与示例提交；顶栏「重置」可恢复演示数据

## 关键实现说明

- 体素用 `Map<"x,y,z", colorIndex>` 存储，序列化时转 entries 数组
- 拾取 ID 编码：`(体素排序序号+1)*8 + 面号`，低 3 位存面号，24 位 RGB 可支持约 200 万面
- 旋转后只画当前视角的两个可见侧面，被相邻体素挡住的面直接跳过
- 贪心减面沿三个轴切片生成带符号颜色掩码，再做矩形扩张合并；OBJ 四边形按面法线保持外向绕序
